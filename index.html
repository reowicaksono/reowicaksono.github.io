Kebijakan Privasi SeduLink

Terakhir diperbarui: 23-09-2026

SeduLink ("Aplikasi") adalah aplikasi Human Resource Information System (HRIS) yang digunakan oleh karyawan untuk melakukan absensi, pengajuan cuti, melihat slip gaji, dan menerima pengumuman dari perusahaan tempat Anda bekerja. Aplikasi ini dikembangkan dan dioperasikan oleh SeduLink ("kami").

Kebijakan Privasi ini menjelaskan data apa saja yang kami kumpulkan melalui Aplikasi, bagaimana data tersebut digunakan, disimpan, dan dilindungi. Dengan menggunakan Aplikasi, Anda menyetujui praktik yang dijelaskan di halaman ini.

Catatan tentang multi-perusahaan (multi-tenant): SeduLink dapat digunakan oleh lebih dari satu perusahaan sebagai pengguna terpisah. Data Anda (absensi, cuti, gaji, dsb.) hanya dapat diakses oleh HR/Admin dari perusahaan tempat Anda terdaftar, dan secara teknis terisolasi dari perusahaan lain pengguna Aplikasi.

2. Bagaimana Kami Menggunakan Data Anda

  • Menyediakan fitur inti Aplikasi: absensi, pengajuan & riwayat cuti, slip gaji, dan pengumuman perusahaan.
  • Memverifikasi identitas Anda saat login.
  • Mengirim notifikasi terkait pengumuman atau status pengajuan Anda.
  • Menjaga keamanan akun dan mencegah penyalahgunaan (mis. deteksi akses tidak sah).

Kami tidak menggunakan data Anda untuk iklan, dan tidak menjual atau membagikan data pribadi Anda kepada pihak ketiga di luar keperluan operasional Aplikasi (mis. penyedia layanan hosting server dan notifikasi push).

3. Penyimpanan & Keamanan Data

  • Seluruh komunikasi antara Aplikasi dan server dienkripsi menggunakan HTTPS.
  • Token sesi login disimpan secara terenkripsi di perangkat Anda (Android Keystore / iOS Keychain), tidak dalam bentuk teks biasa.
  • Data perusahaan Anda secara teknis terpisah (terisolasi) dari data perusahaan lain pengguna Aplikasi.
  • Akses ke data absensi, cuti, dan gaji Anda dibatasi hanya untuk Anda sendiri dan HR/Admin dari perusahaan tempat Anda bekerja.

5. Penyimpanan & Penghapusan Data

Data Anda disimpan selama akun Anda aktif digunakan oleh perusahaan tempat Anda bekerja. Karena Aplikasi ini bersifat internal perusahaan, permintaan penghapusan atau koreksi data pribadi dapat diajukan melalui HR/Admin perusahaan Anda, atau langsung menghubungi kami melalui kontak di bagian bawah halaman ini.

6. Berbagi Data dengan Pihak Ketiga

Kami hanya membagikan data seminimal mungkin kepada penyedia layanan berikut, semata untuk menjalankan fungsi Aplikasi:

  • Firebase Cloud Messaging (Google) — untuk mengirim notifikasi push.
  • Penyedia hosting server Hostinger — untuk menyimpan data operasional Aplikasi.

7. Anak-Anak

Aplikasi ini ditujukan untuk karyawan perusahaan (dewasa) dan tidak ditujukan atau dipasarkan untuk anak-anak di bawah usia 18 tahun.

8. Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Perubahan akan diinformasikan melalui pembaruan tanggal di bagian atas halaman ini.
